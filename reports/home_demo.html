One thing changed from the approved spec

The spec's headline feature was a propagation lag — "global fired eight weeks ago, India hasn't yet." I built it, measured it across all 14 themes on 2012–2026 history, and it does not exist. Correlation decays monotonically from lag zero: ai_compute runs 0.48 → 0.39 → 0.27 → 0.12 across 0/4/8/12 weeks. India's legs move with their global counterparts, not behind them.

So the screen shows divergence instead: how far India's leg has drifted from its global leg versus that pair's own history. Because the legs correlate only loosely (peak r ≈ 0.2–0.5), the gap between them moves a lot — which makes it measurable in a way a fixed lag never was. Whether wide gaps actually close is a Stage 3 backtest question, and the copy is written as observation, not prediction.

Worth a look

One card, not five. The screen surfaces the single strongest reading and states the arithmetic behind it — percentile, standard deviations, both legs — so you can disagree with it. A signal you cannot audit is a signal you should not act on.

3

Two colours, one meaning

Marigold is always India, cyan is always global — in the sparklines, the legend, everywhere. The two-leg structure is the core of the data model, so it gets the colour system rather than the decoration.

Each sparkline rebases both legs to 100 at the start of an 18-month window on a shared scale, so the gap between the lines is the divergence the card describes.

4

Stage, then strength

Stage answers "where in its life is this theme"; confluence answers "how aligned are daily, weekly and monthly". Ordering matters in the classifier — CROWDED is tested before ACCELERATING, so a theme that has already run hard is never dressed up as a fresh entry.

5

The empty Gems tab is the point

It would be easy to rank these 208 names on price momentum today and call it a score. That would be a momentum screen with a better logo. The tab stays empty until fundamentals with real filing dates land at Stage 2.
